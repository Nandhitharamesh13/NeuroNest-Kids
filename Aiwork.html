NeuroNest Kids — Adaptive Difficulty Intelligence System

Technical Reference  |  February 2026

1. Overview — What the AI Does

NeuroNest Kids uses a two-layer adaptive intelligence system to personalise each child's learning experience in real time. The system monitors how many answers a child gets right or wrong, how quickly they respond, and long-term patterns across sessions — then automatically adjusts the difficulty of every single question to keep the child in an optimal learning zone.

The AI never lets a child stay bored (too easy) or become frustrated (too hard). This is especially important for children with autism spectrum disorder (ASD) or learning differences, who may be deeply disrupted by failure or long streaks of the same easy content.

Core Principle — Goldilocks Zone: The AI targets a difficulty level where the child gets roughly 70–80% of questions right. Not too easy (boring), not too hard (frustrating). Just right.

2.2 The Decision Algorithm

Step 1: Is questionsAnswered less than 5? → Always stay EASY (let the child warm up) Step 2: Is currentAccuracy at or above 80%? → Show HARD question every 2nd question (challenge mode) Step 3: Is currentAccuracy below 50%? → Stay EASY (child is struggling) Step 4: Is currentAccuracy between 50 and 80%? → Show HARD question every 3rd question, but only after Q7

3. Layer 2 — Cloud Cognitive AI

3.1 What It Does

Layer 2 runs as a Supabase Edge Function called adaptive-ai-helper. It is invoked asynchronously so it never blocks gameplay. It handles:

  • Personalised encouragement when a child is struggling
  • Question-specific hints when the child requests help
  • Real-time support checks — proactive suggestions to slow down or take a break
    • session_summaryEnd of gameFull performance summary with encouragement
  • Long-term profile updates — updates child_behavior_profiles in the database

4. Complete Data Flow — One Game Session

Parent opens app → selects child → AlphabetGame loads │ ▼ [Layer 2] Loads child_behavior_profiles from database → Sets base difficulty level (e.g., 3) │ ▼ Round 1 begins [Layer 1] computeLevel(): consecutiveWrong=0, streak=0, mode='easy', base=3 → Level 3 → buildOptions(target, 3) → random options │ 7 correct answers (Q8, accuracy 100%, streak 7) ▼ [Layer 1] calculateShouldShowHard(): accuracy (100%) >= 80% → hard every 2nd → currentDifficulty = 'hard' computeLevel(): mode='hard', streak=7>=5 → Level 5 (EXPERT) → makeQuestion: emoji only, confusing options (e.g. X, K, R, Y) │ Child answers incorrectly at Level 5 ▼ [Layer 1] recordWrong(): consecutiveWrong++ (1) → Level 4 (Hard) next round │ 2 more wrong answers → consecutiveWrong = 3 ▼ [Layer 1] Level 1 (Very Easy), FAR_APART options [Layer 2] trackWrong(): consecutiveWrong >= frustration_threshold → calls 'get_encouragement' → encouragement bubble shown on screen │ Game ends (10 rounds completed) ▼ [Layer 2] updateStats() → updates average_accuracy, strong_categories [Layer 2] adjustDifficulty() → writes new current_difficulty_level for next session

5. Summary — Why This Approach Works

  • Layer 1 is instant — no network delay. Every answer updates difficulty in the same millisecond.
  • Layer 2 is powerful but non-blocking — enriches the experience without slowing the game.
  • 5 levels are invisible to the child — the child never sees "Level 4". The questions just feel different.
  • Long-term memory — the child's profile persists across sessions; AI starts at the right level next time.
  • Failure-safe — if cloud AI fails (network error), Layer 1 continues working perfectly.
