# NeuroNest Kids - Frontend Application

This folder contains the React + Vite frontend for the NeuroNest Kids learning platform.

## Quick Start

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
├── components/      # React components
├── pages/          # Page routes
├── hooks/          # Custom hooks
├── api/            # API integration
└── main.tsx        # Entry point
```

## Local Development

The frontend runs on `http://localhost:5173` and connects to the backend at `http://localhost:5000`.

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## How can I deploy this project?

Deploy the project using standard frontend or static site hosting services such as Vercel, Render, or Netlify. The app is built with Vite and outputs a production-ready `dist` folder.

## Can I connect a custom domain?

Yes, you can!

After deploying the site, configure your DNS provider or deployment platform to point your custom domain to the hosted frontend URL.

If you need instructions, use the deployment guide in the repository.
